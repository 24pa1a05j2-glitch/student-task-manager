# StudyFlow — Student Task Manager
## Final Web Development Internship Project Report

**Project Title:** StudyFlow — Student Task Manager

**Project Objective:** The objective of StudyFlow is to provide students with a simple, responsive, and interactive website for organizing academic tasks, tracking deadlines, and monitoring completion progress.

**Project Overview:** StudyFlow is a browser-based task management dashboard built with HTML, CSS, and JavaScript. Students can add assignments, enter descriptions and due dates, choose a priority, and update each task's status. Summary cards display total tasks, tasks still in progress, completed tasks, and overdue tasks. The interface uses a clean dashboard layout to make information easy to scan and manage.

**Technologies Used:** HTML5, semantic HTML elements, CSS3, Flexbox, CSS Grid, media queries, JavaScript ES6, DOM manipulation, event listeners, arrays, objects, form validation, and browser localStorage. Git and GitHub are used for version control and repository hosting, while GitHub Pages is used for deployment.

**Main Features:** The website supports creating, editing, deleting, and completing tasks. Search allows users to find tasks by title or description. Status and priority filters narrow the displayed list. Due dates are formatted for readability, and unfinished tasks past their due date are marked overdue. Progress indicators update dynamically. Tasks persist after refreshing the browser through localStorage. The interface includes validation messages, confirmation prompts, feedback notifications, mobile navigation, and responsive layouts for desktop, tablet, and mobile screens.

**Challenges Faced:** A key challenge was updating the task list and summary statistics consistently when tasks changed. Another challenge was keeping the dashboard usable on narrow screens while retaining useful controls.

**Solutions Implemented:** Rendering was separated into reusable functions, and event listeners handle form submissions, task actions, search, and filters. CSS Grid, Flexbox, and media queries adapt the layout to different screen sizes. Input validation and confirmation dialogs help prevent accidental or incomplete actions. localStorage provides simple persistence without requiring a server.

**Key Learnings:** This project strengthened my understanding of semantic HTML, CSS layout techniques, responsive design, JavaScript functions, arrays, objects, events, DOM updates, validation, and browser storage. I also practised Git commands, meaningful commit messages, GitHub repository organization, and static website deployment.

**Future Improvements:** Possible improvements include user accounts, cloud synchronization, recurring reminders, calendar integration, drag-and-drop task ordering, and a backend database for accessing tasks across devices.

**Conclusion:** StudyFlow brings together the main concepts covered during the six-week web development internship in a practical project. It provides a usable student-focused tool and demonstrates the workflow from planning and coding to version control, testing, documentation, and deployment.
